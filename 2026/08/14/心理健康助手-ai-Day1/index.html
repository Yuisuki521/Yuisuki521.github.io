心理健康助手+ai Day1

2026/8/14 学习

今天是心理健康助手＋ai项目的第一天，是我的第一个项目

1.nvm和node版本

需要用到node的24版本，所以学习用到了nvm，可以调节node的不同版本，node也十分方便管理这些版本，用到了一些基本命令像
nvm list
nvm install 24
nvm use 24

2.vite脚手架工具

vue3需要依赖脚手架工具，这里我学习用到了vite
npm create vite@latest快速创造项目

3.创造管理员页面

vue-router

使用组件库element plus，安装后引入，考虑到管理员和使用者的双页面，所以定义路由时需要将两个板块分开，认识并使用vue-router插件，这里使用4.0版本
安装npm install vue-router@4.6.4。

配置路由

创建router文件夹，其下创建index.js文件引入vue-router，使用history模式，并创建后台管理管理路由backendroutes，backendroutes创建集合，主路由为/back，使用嵌套模式，为了引入backendlayout(子路由先不动)
在components文件夹下创建backendlayout.vue，在index.js文件中引入backendlayout.vue
创建对象接收创造的router，并导出，在入口文件中引入router并挂载进去，在backendlayout文件使用router标签
(遇到@服务问题，找到vite配置文件，使用resolve进行路径拼接)
在elementplus中找到合适框架加入到backendlayout，这里使用ai将引入的框架进行调整，达到填充合适并美观的样子
