心理健康助手-ai-Day11

2026/8/25

今天是心理健康助手＋ai项目的第十一天，做了登出部分和页面首页展示

1.登出和导航守卫

这里的登出是在一个组件里，有一个command值，退出时需要把用户信息和token清除并跳转到登录页面，提示依旧使用ElmssageBox组件，创建接口lgout并引入，在这个command值等于lgout时，调用接口，在调用后在返回的响应里做token和用户信息的清除与页面的跳转。
接下来是只输入端口号就可以进入到首页的跳转，在路由部分添加路由的前置守卫，通过调用router.beforeEach的方法传入三个参数，要实现访问/时可以直接跳转到页面，当未登录时/可直接跳转到登录页面，登录后台账号时，直接跳转到后台页面，在原来后台部分添加重定向逻辑redirect，直接返回到页面，在前置守卫中通过localStorge.getItem得到token数据，判断如果token存在，就为登录，当用户没有登陆时，对于后台用户直接跳转到登录页面，对于前台用户来说 会跳到首页，所以要判断用户是前台登录还是后台登录，通过判断路径，所有后台数据都是带有/back，通过to.path为即将跳转的路径，当有/back时候可以判断为后台登录，跳转为未登录页面；登录时也要判断是前台用户还是后台用户，通过判断userInfo的userType转为json数据为2时为后台用户，再下一步判断这个上面说的页面登陆是否为后台登录/back,判断成功后即使不为/back，也跳转进后台首页，结构图为

router.beforeEach(to, from, next)
│
├─ 读取 token = localStorage.getItem(‘token’)
│
├─ [token 存在?]
│ │
│ ├─ YES → 读取 userInfo = JSON.parse(localStorage.getItem(‘userInfo’))
│ │ │
│ │ ├─ [userType === 2] (管理员)
│ │ │ ├─ to.path 以 ‘/back’ 开头?
│ │ │ │ ├─ YES → next() ✅ 放行
│ │ │ │ └─ NO → next(‘/back/dashboard’) 🔄 强制进后台
│ │ │
│ │ └─ [userType === 1] (普通用户)
│ │ └─ (目前为空逻辑,无 next 调用)
│ │
│ └─ NO → [to.path 以 ‘/back’ 开头?]
│ ├─ YES → next(‘/auth/login’) 🔄 跳登录
│ └─ NO → next() ✅ 放行
