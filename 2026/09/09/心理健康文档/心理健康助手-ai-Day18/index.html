现在来写后端的实现过程，

1.JWT认证和token创建

token有三部分头部 载荷 签证，头部为声明方式，加密算法，载荷为数据部分。使用外部插件实现JWT引入java-jwt；在yml文件里给jwt设置配置；接下来在config里设置配置项新建文件JwtConfig，将在yml文件里配置的属性定义，通过@ConfigurationProperties(prefix=”jwt”)指定将数据传入进来，加@Data和@Compenent；新建util文件夹新建JwtTokenUtil文件，在JwtTokenUtil创建生成token的方法generateToken，传入userId,username roleType，接下来需要传入jwtConfig里的属性，通过传入上下文处理，首先要继承ApplicationContextAware接口，对里面的方法进行重写
@Override
public void setApplicationContext(ApplicationContext applicationContext) {
JwtTokenUtil.applicationContext(上方已定义) = applicationContext;
}
private static JwtConfig getJwtConfig() {
return applicationContext.getBean(JwtConfig.class); //拿到定义好的jwt属性
};
接下来获取jwt属性，直接通过getJwtConfig()拿到jwt属性
Algorithm algorithm = Algorithm.HMAC256(jwtConfig.getSecret()); //生成签名的算法
Date expiration = new Date(System.currentTimeMillis() + jwtConfig.getExpiration()); //生成过期时间
String token = JWT.create()
.withClaim(“userId”, userId)
.withClaim(“username”, username)
.withClaim(“roleType”, roleType)
.withExpiresAt(expiration) // 设置过期时间
.withIssuedAt(new Date()) // 设置签发时间
.withIssuer(ISSUER) // 设置签发者，在上方定义
.sign(algorithm);
return token;最后try catch一下。

2.实现注册接口

在controller层继续注册接口/add，返回结果为用户表的信息UserLoginResponseDTO.UserDetailResponseDTO，注册内容也需要进行校验，需要定义实体类在command新建UserRegisterCommandDTO，定义属性添加Data注解校验逻辑，在安全校验添加此接口,通过调用userService.register(commandDTO)。
回到service层，定义方法register返回类型UserLoginResponseDTO.UserDetailResponseDTO,引入hutool工具可以在后台打印出，通过JSONUtil.parseObj(commandDTO)就可以打印出commmand的json格式数据。接下来实现验证两次密码输入一致的逻辑通过commandDTO.getPassword()拿到数据比较再次输入的密码；接下来验证用户名是否存在，首先构建查询条件，新建LambdaQueryWrapper类型类queryWrapper，传入User，调用eq方法进行比较，构建好了查询条件，然后判断这个用户名数量如果大于0，那么用户名已经存在；接下来检查邮箱是否存在，一样的流程；验证用户类型，在UserType里的isValidCode方法可以将传入数据进行比较是否为枚举类，直接使用这个方法判断用户类型；最后一部是创建用户，需要将数据插入进数据库，用同样方法进行密码的passwordEncoder.encode(password)(将password定义出来)，然后创建实体类就是使用之前登录的实体类User；接下来需要将拿到的DTO转换为User实体，需要重新构建转化类，在UserConvert新建类
public static User registerCommandToEntity(UserRegisterCommandDTO commandDTO, String encodedPassword){}
，通过实体类进行构建，在User实体类添加Builder注解，然后通过.builder()方法构建(对照user表)，其中status需要从枚举处拿到正常code，创建好转换为实体的方法后，回到UserService，调用刚才定义的方法，最后插入数据库userMapper.insert()，返回
return UserConvert.entityToDetailResponse(user)；可以在controller层对外暴露，验证在数据库可以成功出现新用户。
