心理健康助手-ai-Day21

2026/9/16 学习

1.AI对话创建对话

先是创建会话接口，再调用AI回复流式接口响应，先做会话创建接口，在controller层创建单独模块PsychologicalChat，添加注解，接口为startSession是post请求，返回值通过看前端内容，需要定义出来，新建AiService文件夹，新建StructOutPut定义返回值内容
public record StreamChatSession(
String sessionId,
Long userHash,
String initialMessage,
Long startTime,
Long expireTime,
Integer messageCount,
String status
){}
前端返回值为两个，用户输入内容和聊天标题，需要定义并添加校验逻辑，在DTO的common里新建ConsultationSessionCreateDTO，要求对比数据库
@Data
public class ConsulationSessionCreateDTO {
@Size(max = 200, message = “会话标题长度不能超过200个字符”)
private String sessionTitle;

@NotBlank(message = "会话消息不能为空")
@Size(max = 2000, message = "会话消息长度不能超过2000个字符")
private String initialMessage;

}
回到controller层，将刚才的DTO传入进去，接下来要把这条聊天记录加入进数据库consulation_session，获取当前用户。

2.AI对话Service层创建对话数据

在AiService文件夹新建PsychologicalSupportService类，定义方法
public StructOutPut.StreamChatSession startSession(Long userId, ConsulationSessionCreateDTO createDTO) {}
在controller层引入并使用PsychologicalSupportService类，回到Service层，需要创建数据库会话记录，在Service文件夹新建ConsultationSessionService类
public ConsultationSession createSession(Long userId, ConsulationSessionCreateDTO createDTO)
建ConsultationSession实体类，连接数据库@TableName(“consultation_session”)，创建完后回到ConsultationSessionService，验证用户是否存在
User user = userMapper.selectById(userId);
if(user != null){
//创建会话记录
ConsultationSession session = ConsultationSession.builder()
.userId(userId)
.sessionTitle(createDTO.getSessionTitle())
.startedAt(LocalDateTime.now())
.build();
//如果未提供标题
if(StrUtil.isBlank(createDTO.getSessionTitle())){
session.setSessionTitle(String.format(“艾拉AI助手 - %s”, DateUtil.format(LocalDateTime.now(), “MM-dd HH:mm”)));
}
//插入记录
consultationSessionMapper.insert(session);
return session;
}
新建consultationSessionMapper。
