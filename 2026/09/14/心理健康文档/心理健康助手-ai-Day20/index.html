1.从token提取信息

token存在时，验证token并获取用户信息，再JwtTokenUtil里封装方法validateToken用来验证token返回类型为TokenVerificationResult(创建token验证结果封装类TokenVerificationResult，添加属性和构造函数)，将token传递进去，需要先验证是否为有效token(封装方法verifyToken返回类型为DEcodedJWT，判断token格式是否合法，如果非法抛出错误，合法时进行解码
JwtConfig jwtConfig = getJwtConfig();
Algorithm algorithm = Algorithm.HMAC256(jwtConfig.getSecret());
JWTVerifier verifier = JWT.require(algorithm)
.withIssuer(ISSUER)
.build();)
调用方法verifyToken，然后接收数据，调用DecodedJWT的get方法，进行类型转换后拿到解码后信息，角色类型需要
Integer roleType = null;
try{
roleType = jwt.getClaim(“roleType”).asInt();
}catch (Exception e){
String roleTypeStr = jwt.getClaim(“roleType”).asString();
if(StringUtils.hasText(roleTypeStr)){
roleType = Integer.valueOf(roleTypeStr);
}
}

还需要再判断userId != null && StringUtils.hasText(username) && roleType != null，拿到token有意义的数据，最后回到验证方法里调用方法，将token传入，用validationResult接收有效数据，如果validationResult不为空，并且validationResult.isValid()不为空，那么根据解密出来的userId查询用户信息验证用户状态，在UserService层中创建方法getUserById，返回类型为UserLoginResponseDTO.UserDetailResponseDTO，传入token中解码的userId，通过userMapper.selectById方法查询，然后拿到用户数据user，如果user为null对外抛出异常，为正常数据时将用户实体转换为响应类，否则清除上下文再给前端返回结果枚举里的token错误。
然后回到过滤器引入并调用userService.getUserById(validationResult.getUserId)，用user接收一下，将user数据JSONUtil.parseObj(user)打印查看结果是否合理；接下来将查询的数据进行判断user != null && UserStatus.NORMAL.getCode().equals(user.getStatus())，如果没问题，
接下来创建Spring Security认证对象
List authorities = Collections.singletonList(new SimpleGrantedAuthority(“ROLE_” + validationResult.getRoleType()));
然后创建UsernamePasswordAuthenticationToken对象
UsernamePasswordAuthenticationToken authcation = new UsernamePasswordAuthenticationToken(validationResult.getUsername(), null, authorities);
设置认证信息到Spring Security上下文
SecurityContextHolder.getContext().setAuthentication(authcation);
最后将token存贮到请求的属性中
request.setAttribute(“jwtToken”, token);
回到controller层，处理从token中解析出用户的id逻辑，需要封装方法获取jwtToken，在JwtTokenUtil中
public static String getCurrentToken() {
ServletRequestAttributes attributes = (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
if(attributes != null){
HttpServletRequest request = attributes.getRequest();
String token = (String) request.getAttribute(“jwtToken”);
if(token != null){
return token;
}

        //从请求头中获取token
        String headerToken = extractTokenFromRequest(request);
        return headerToken;
    }
    return null;
}

回到controller层
//从token中获取用户ID
String token = JwtTokenUtil.getCurrentToken();
DecodedJWT jwt = JwtTokenUtil.verifyToken(token);
Long userId = jwt.getClaim(“userId”).asLong();
//调用服务层获取用户详情方法
UserLoginResponseDTO.UserDetailResponseDTO result = userService.getUserById(userId);
；否则抛出用户异常，清除上下文打印错误
