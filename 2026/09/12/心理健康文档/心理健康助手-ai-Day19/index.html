2026/9/12 学习

现在来写后端的实现过程，

1.获取当前用户

不需要前端传递参数，只需要token信息就可以，此接口需要通过安全验证，从token中提取出userId数据。首先定义接口get请求(“/current”)，返回类型为Result<UserLoginResponseDTO.UserDetailResponseDTO>，起名为getCurrentUser。
从token中拿到userId，需要对之前安全拦截框架增加拦截后的处理逻辑，添加JWT认证过滤器，在util文件夹下定义过滤器方法JwtAuthicationFilter继承OncePerRequestFilter(为保证通过过滤器方法只通过一次)，对方法进行重写：

公开路径处理逻辑

protected boolean shouldNotFilter(HttpServletRequest request) {
String requestUrl = request.getRequestURI();
return SecurityConfig.isPublicPATH(requestUrl);
} (不需要过滤的方法)
拿到request请求，在SecurityConfig中定义isPublicPATH方法来检验公共路径有没有request的这条路径，接收请求的地址requsetUrl，在方法里面判断requsetUrl是否在公共路径中，引入AntPathMatcher来进行路径对比
public static Boolean isPublicPATH(String requestUrl) {
for (String publicPath : PUBLIC_PATHS) {
if (antPathMatcher.match(publicPath, requestUrl)) {
return true;
}
}
return false;
}

回到JwtAuthicationFilter
protected void doFilterInternal(
HttpServletRequest request,
HttpServletResponse response,
FilterChain chain) throws ServletException, IOException{}
对方法进行重写，先获取请求的URL和方法
String requestUrl = request.getRequestURI();
String method = request.getMethod();
打印上方两条数据，将现在编写的JwtAuthicationFilter方法引入添加到处理的地方，在apifox里进行测试，打印出url和get请求。

2.JWT认证流程

提取JWT的token在JwtTokenUtil方法中创建提取token方法extractTokenFromRequest，参数从request中拿到首先判断request是否存在直接返回null，如果存在从header中拿到token，创建tokenHeader接收，通过StringUtils.hasText(tokenHeader)判断tokenHeader是否为正确，正确就返回出去，否则返回null，回到JwtAuthicationFilter，拿到token，然后进行判断token是否存在，如果不存在需要清理上下文，单独创建清理Spring Security上下文方法clearSecurityContext。
private void clearSecurityContext() {
SecurityContextHolder.clearContext();
}
如果token未获取到就调用方法清理上下文，还需要向外部返回错误提示，需要在Util层新建ResponseUtil单独处理过滤器中的异常相应(之前定义的Result是在进入controller层之前，所以不能使用)，实现方法
public static void writeError(HttpServletResponse response, ResultCode resultCode){
//根据不同结果码返回不同的响应
int status = switch (resultCode){
case UNAUTHORIZED, ACCESS_UNAUTHORIZED, TOKEN_INVALID, TOKEN_EXPIRED, TOKEN_BLOCKED -> HttpStatus.UNAUTHORIZED.value();
case TOKEN_ACCESS_FORBIDDEN -> HttpStatus.FORBIDDEN.value();
default -> HttpStatus.BAD_REQUEST.value();
};
response.setStatus(status);
response.setContentType(MediaType.APPLICATION_JSON_VALUE);
response.setCharacterEncoding(StandardCharsets.UTF_8.name());

    try (PrintWriter writer = response.getWriter()){
        String jsonResponse = JSONUtil.toJsonStr(Result.error(resultCode.getCode(), resultCode.getMsg(), null));
        writer.print(jsonResponse);
        writer.flush();//确保响应写入到输出流
    }catch (IOException e){
        System.out.println("写入响应失败："+e.getMessage());
    }
}

再将方法使用，token没有问题时再继续过滤器链，下节我们写token存在时的逻辑。
chain.doFilter(request, response);
